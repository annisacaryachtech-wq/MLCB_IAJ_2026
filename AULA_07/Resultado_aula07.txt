#EXERCÍCIO 01: - PRÉ-PROCESSAMENTO

Código:

tokens = ["os", "produtos", "comprados", "não", "chegaram"]
stopwords = ["os", "não"]

tokens_limpos = []

for palavra in tokens:
    if palavra in stopwords:
        continue
    elif palavra == "comprados":
        tokens_limpos.append("comprar")
    elif palavra == "chegaram":
        tokens_limpos.append("chegar")
    else:
        tokens_limpos.append(palavra)

print(tokens_limpos)

Saída:
['produtos', 'comprar', 'chegar']

#RESPOSTA: O Stemming corta partes da palavra e pode gerar palavras que não existem. Lematização busca a forma correta da palavra no dicionário






#EXERCÍCIO 02: - VALIDAÇÃO DE NLU


Código:

def validar_intencao(confianca):
    if confianca >= 0.70:
        return "Ação Executada"
    else:
        return "Fallback Acionado"

print(validar_intencao(0.55))

Saída:
Fallback Acionado

#RESPOSTA: Se o limite fosse apenas 20%, o sistema poderia considerar uma resposta com pouca confiança como correta. Em um banco, isso poderia fazer o sistema executar ações erradas, como identificar uma intenção incorretamente ou realizar uma operação que o cliente não pediu
