#EXERCÍCIO 01: - PRÉ-PROCESSAMENTO


tokens = ["os", "produtos", "comprados", "não", "chegaram"]
stopwords = ["os", "não"]

tokens_limpos = []

for palavra in tokens:
    if palavra in stopwords:
        continue
    elif palavra == "comprados":
        tokens_limpos.append("comprar")
    elif palavra == "chegaram":
        tokens_limpos.append("chegar")
    else:
        tokens_limpos.append(palavra)

print(tokens_limpos)

Saída:
['produtos', 'comprar', 'chegar']

#RESPOSTA: O Stemming corta partes da palavra e pode gerar palavras que não existem. Lematização busca a forma correta da palavra no dicionário

#EXERCÍCIO 02: - VALIDAÇÃO DE NLU




def validar_intencao(confianca):
    if confianca >= 0.70:
        return "Ação Executada"
    else:
        return "Fallback Acionado"

print(validar_intencao(0.55))

Saída:
Fallback Acionado

#RESPOSTA: Se o limite fosse apenas 20%, o sistema poderia considerar uma resposta com pouca confiança como correta. Em um banco, isso poderia fazer o sistema executar ações erradas, como identificar uma intenção incorretamente ou realizar uma operação que o cliente não pediu

#EXERCÍCIO 03: - PONDERAÇÃO DE PALAVRAS - TF-IDF



def calcular_peso_tfidf(frequencia_geral):
    if frequencia_geral == "muito_frequente":
        return 0.1
    elif frequencia_geral == "pouco_frequente":
        return 0.9

print(calcular_peso_tfidf("pouco_frequente"))

Saída:
0.9

#RESPOSTA: As palavras comuns recebem peso baixo porque aparecem muito e Palavras raras recebem peso alto porque ajudam mais a diferenciar os textos

#EXERCÍCIO 04: - MÉTRICAS DE AVALIAÇÃO - PRECISÃO




vp = 80
fp = 20
fn = 5

precisao = vp / (vp + fp)

print(f"{precisao * 100:.2f}%")

Saída:
80.00%

#RESPOSTA: Um Falso Positivo acontece quando o sistema identifica uma compra normal como fraude, isso pode causar bloqueio de uma compra verdadeira e prejudicar o cliente e um Falso Negativo acontece quando o sistema não percebe uma fraude que realmente aconteceu e Nesse caso, a empresa pode perder dinheiro diretamente com a fraude

#EXERCÍCIO 06: - REPRESENTAÇÃO VETORIAL



def sao_sinonimos(distancia):
    if distancia < 0.20:
        return True
    else:
        return False

print(sao_sinonimos(0.05))

Saída:
True

#RESPOSTA: O TF-IDF olha para a frequência das palavras, mas não entende seus significados, já os Word Embeddings conseguem aproximar palavras com significados parecidos, como “aluguel” e “locação”

#EXERCÍCIO 07: - LIMPEZA DE TEXTO



bruta = ["O", "sistema", "está", "muito", "lento", "hoje", "!"]
stopwords = ["O", "está"]

tokens_limpos = []

for palavra in bruta:
    if palavra not in stopwords and palavra != "!":
        tokens_limpos.append(palavra)

print(tokens_limpos)

Saída:
['sistema', 'muito', 'lento', 'hoje']


#RESPOSTA: Stopwords são palavras que aparecem muito nos textos e geralmente não acrescentam muita informação para algumas tarefas. A remoção delas pode diminuir o tamanho do texto e ajudar o sistema a dar mais atenção às palavras que realmente são importantes

EXERCÍCIO 10 - SELEÇÃO DE INTENÇÃO E FALLBACK



probabilidades = [0.25, 0.30, 0.15]
limiar = 0.60

maior_confianca = max(probabilidades)

if maior_confianca >= limiar:
    print("Intenção Confirmada")
else:
    print("Acionar Fallback")

Saída:
Acionar Fallback

#RESPOSTA: Quando o chatbot não tem confiança suficiente para identificar a intenção, ele pode pedir para o usuário explicar ou reformular o que deseja. O objetivo do Fallback é evitar que o sistema escolha uma intenção errada e tentar conseguir mais informações do usuário
